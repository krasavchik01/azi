**Традиционная русская карточная игра на взятки с торговлей и козырями**

## 📖 Описание

**АЗИ** - это азартная карточная игра, где цель - первым взять две взятки. Игра сочетает элементы стратегии, удачи и психологии, включая торговлю (повышение ставок), систему козырей и уникальные правила "разномасть" и "на ази".

## 🎯 Основные Правила

### Колода и Игроки
- **Колода**: 27 карт (3 масти: ♥ черви, ♦ бубны, ♣ трефы)
- **Ранги**: 6, 7, 8, 9, 10, В (валет), Д (дама), К (король), Т (туз)
- **Игроки**: от 2 до 6 человек
- **Старшинство**: 6 < 7 < 8 < 9 < 10 < В < Д < К < Т

### Цель Игры
**Первым взять две взятки** в раунде

## 🎲 Ход Игры

### 1. Начальная Ставка
- Перед началом каждый игрок вносит **базовую ставку** (по умолчанию 5₽)
- Все деньги идут в **кон** (банк)
- Игроки начинают со 100₽ стартового капитала

### 2. Раздача Карт
- Сдатчик определяется жребием (затем по очереди)
- Каждому игроку сдается **по 4 карты**
- **Последняя карта сдатчика** открывается - её масть становится **козырем**

### 3. Сброс Карты
- После объявления козыря игроки решают: играть или сбросить карты
- Игроки, которые **не хотят играть**, сбрасывают все карты
- Игроки, которые **согласны играть**, сбрасывают **одну любую карту**
- У каждого остается **3 карты**

### 4. Торговля (Повышение Ставок)
- Начинает игрок **слева от сдатчика**
- Каждый игрок может:
  - **Пас** - не повышать ставку
  - **Повысить** - увеличить ставку на любую сумму
  - **Сбросить** - выйти из раунда
- Максимум **3 повышения** на всех игроков
- Торговля заканчивается когда все спасовали или достигнут лимит

### 5. Розыгрыш
- Первым ходит игрок **справа от победителя торгов**
  (упрощено: слева от сдатчика)
- **Правила хода**:
  - Если есть карта **той же масти** - обязательно играть её
  - Если нет карты той масти - играть **козырь**
  - Если нет ни масти, ни козыря - любую карту
- **Взятку берет** игрок с самой старшей картой:
  - Козырь бьет некозырную карту
  - Старший козырь бьет младший козырь
  - Старшая карта масти хода бьет младшую
- Победитель взятки ходит первым в следующей

### 6. Победа
- **Игрок взявший 2 взятки** выигрывает раунд и забирает кон
- Начинается новый раунд (сдатчик меняется)

## 🎴 Специальные Правила

### "Разномасть"
Игрок, имеющий **козырного туза** и **две карты одной масти**, может объявить "разномасть":
- При первом ходе в другую масть **не обязан** бить козырным тузом
- При втором ходе в ту же масть **обязан** бить тузом

### "На Ази"
Два игрока могут договориться играть "на ази":
- Цель: **не дать другим** взять более одной взятки
- Если один из них взял 2 взятки - **не забирает кон**
- Участвует в переигровке как взявший 1 взятку

## 🔄 АЗИ (Ничья)

Если **никто не взял 2 взятки**, происходит **АЗИ** (переигровка):

- **Игроки с 1 взяткой** - играют бесплатно
- **Игроки с 0 взяток** - вносят **половину базовой ставки**
- **Игроки сбросившие карты** - вносят **полную ставку**
- Кон накапливается, раздача повторяется

### Определение козыря при переигровке:
- Если **сдатчик участвует** - открывает свою 4-ю карту
- Если **сдатчик не участвует** - открывается верхняя карта оставшейся колоды

## 🚀 Установка и Запуск

### Требования
- Node.js 14+ и npm

### Установка
```bash
# Клонируйте репозиторий
git clone <repository-url>
cd azi

# Установите зависимости
npm install
```

### Запуск
```bash
# Запустить сервер
npm start

# Для разработки с автоперезагрузкой
npm run dev
```

Откройте браузер: **http://localhost:3000**

### Мультиплеер
1. Откройте **несколько вкладок** браузера (или разные устройства)
2. В каждой введите имя и войдите в лобби
3. Когда соберется 2-6 игроков, любой может нажать "Начать Игру"
4. Играйте!

## 🎮 Как Играть

### Фазы Игры

#### 1. **Лобби**
- Введите имя
- Дождитесь других игроков (минимум 2)
- Нажмите "Начать Игру"

#### 2. **Раздача**
- Получите 4 карты
- Козырь автоматически открывается

#### 3. **Сброс Карты**
- Кликните на карту чтобы сбросить её
- Или нажмите "Сбросить Карты" чтобы выйти из раунда

#### 4. **Торговля**
- В свой ход выберите:
  - **Пас** - не повышать
  - **Повысить** - увеличить ставку (введите сумму)
  - **Сбросить** - выйти из игры

#### 5. **Розыгрыш**
- В свой ход кликните на карту чтобы сыграть её
- Следуйте правилам (масть, козырь)
- Смотрите кто берет взятки

#### 6. **Победа/АЗИ**
- Если взяли 2 взятки - вы выиграли!
- Если АЗИ - готовьтесь к переигровке

## 💡 Стратегия

### Базовые Советы
- **Оценивайте руку**: Есть ли у вас козыри? Сильные карты?
- **Торговля**: Не повышайте со слабой рукой
- **Считайте карты**: Запоминайте что вышло
- **Козыри**: Экономьте для важных моментов
- **Первый ход**: Иногда лучше "вывести" слабую масть

### Продвинутая Тактика
- Используйте "разномасть" с умом
- "На ази" эффективно когда вы сильнее остальных
- При АЗИ - оценивайте стоимость переигровки
- Блефуйте в торговле (осторожно!)

АЗИ - традиционная русская карточная игра, популярная в 19-20 веках. Название происходит от ситуации "ничьей" когда никто не берет нужное количество взяток. Игра сочетает элементы покера (торговля), бриджа (взятки) и преферанса (козыри).
