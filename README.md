## 🌟 О Проекте

**Мила** - это инновационное приложение для ментального здоровья, powered by Claude AI. Это не просто чат-бот - это заботливый AI-психолог, который:

- 💬 **Слушает** тебя без осуждения
- 🧠 **Помнит** вашу историю и контекст
- 💙 **Поддерживает** 24/7, когда тебе это нужно
- 🎯 **Помогает** разобраться в себе и своих чувствах
- 🔒 **Конфиденциально** хранит ваши разговоры

## ✨ Ключевые Особенности

### 🤖 Умный AI с Памятью
- Использует Claude 3.5 Sonnet - самую продвинутую языковую модель
- Запоминает все ваши разговоры и контекст
- Персонализирует советы на основе вашей истории
- Анализирует настроение и эмоции

### 💬 Профессиональный Подход
- Техники когнитивно-поведенческой терапии (КПТ)
- Майндфулнесс и дыхательные упражнения
- Эмпатичное активное слушание
- Помощь в постановке целей

### 🔐 Безопасность и Приватность
- Зашифрованная аутентификация (JWT)
- Хранение истории в защищённой базе данных
- Никакой передачи данных третьим лицам
- Опция работы без базы данных (in-memory)

### 💎 Модель Подписки (Ready to Implement)
- **Free**: 10 сообщений/день
- **Basic**: Безлимитное общение
- **Premium**: Приоритетный доступ + аналитика

## 🚀 Быстрый Старт

### Требования
- Node.js 16+ и npm
- MongoDB (опционально)
- Anthropic API Key ([получить здесь](https://console.anthropic.com/))

### Установка

```bash
# 1. Клонируйте репозиторий
git clone <repository-url>
cd azi

# 2. Установите зависимости
npm install

# 3. Настройте переменные окружения
cp .env.example .env
# Отредактируйте .env и добавьте ваш ANTHROPIC_API_KEY

# 4. Запустите сервер
npm start
```

Откройте браузер: **http://localhost:3000**

### Минимальная Конфигурация (.env)

```bash
# Обязательно
ANTHROPIC_API_KEY=sk-ant-your-api-key-here

# Опционально (работает без MongoDB)
MONGODB_URI=mongodb://localhost:27017/ai-therapist
JWT_SECRET=your-secret-key
PORT=3000
```

## 🧠 Как Работает AI

**Мила** использует промпт-инжиниринг для создания эмпатичной личности:

```javascript
Системный промпт включает:
- Роль профессионального психолога
- Техники КПТ и майндфулнесс
- Эмпатичный стиль общения
- Безопасность (кризисные ситуации)
- Персонализацию на основе контекста
```

### Контекст и Память
Каждый запрос обогащается:
- Именем пользователя
- Предыдущими темами разговоров
- Целями и предпочтениями
- Важными заметками (insights)
