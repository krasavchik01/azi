## 🌟 Описание

**АЗИ** - это динамичная карточная игра для двух игроков, где вы командуете армией существ четырёх стихий: **Огня** 🔥, **Воды** 💧, **Земли** 🌍 и **Воздуха** 💨. Стройте стратегию, играйте картами, атакуйте противника и станьте победителем в битве стихий!

## ✨ Особенности

- 🎲 **Мультиплеер в реальном времени** - играйте против живых противников через WebSocket
- 🃏 **Уникальные карты** - 4 стихии с различными существами и заклинаниями
- ⚔️ **Тактическая глубина** - управляйте маной, выбирайте цели, стройте стратегию
- 🎨 **Красивый интерфейс** - анимации, эффекты и градиенты
- 🏆 **Система редкости** - обычные, редкие, эпические и легендарные карты
- ⚡ **Быстрая игра** - матчи длятся 10-15 минут

## 🎯 Правила игры

### Основы

- **Цель**: Снизить здоровье противника с 30 до 0
- **Стартовая рука**: 4 карты
- **Мана**: Начинается с 1, увеличивается каждый ход (максимум 10)
- **Колода**: 30+ уникальных карт четырёх стихий

### Типы карт

#### 🧙 Существа (Minions)
- Имеют **Атаку** ⚔️ и **Здоровье** ❤️
- Могут атаковать противника или его существ
- **Сонная болезнь**: существа не могут атаковать в ход призыва
- Некоторые имеют уникальные способности

#### ✨ Заклинания (Spells)
- Мгновенный эффект при разыгрывании
- **Урон**: наносят урон противнику или его существам
- **Исцеление**: восстанавливают ваше здоровье
- **Усиление**: улучшают характеристики существ

### Стихии

#### 🔥 Огонь
- **Стиль**: Агрессия и прямой урон
- **Особенности**: Высокая атака, заклинания урона
- **Легенда**: Дракон Пламени (8/8/8)

#### 💧 Вода
- **Стиль**: Контроль и защита
- **Особенности**: Высокое здоровье, исцеление
- **Легенда**: Левиафан (7/6/9)

#### 🌍 Земля
- **Стиль**: Выносливость и усиление
- **Особенности**: Крепкие существа, баффы
- **Легенда**: Титан Земли (9/7/10)

#### 💨 Воздух
- **Стиль**: Скорость и магия
- **Особенности**: Быстрые атаки, дешевые заклинания
- **Легенда**: Повелитель Бури (7/7/6)

## 🚀 Установка и запуск

### Требования

- Node.js 14+ и npm

### Установка

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd azi

# Установите зависимости
npm install
```

### Запуск

```bash
# Запустить сервер
npm start

# Для разработки с автоперезагрузкой
npm run dev
```

Откройте браузер и перейдите по адресу: **http://localhost:3000**

### Игра с другом

1. Запустите сервер
2. Откройте **два окна браузера** (или два устройства в одной сети)
3. В каждом окне перейдите на http://localhost:3000
4. Введите имена и нажмите "Начать игру"
5. Игроки автоматически будут сматчены!

## 🎮 Как играть

### 1. Начало игры
- Введите своё имя
- Дождитесь подключения противника
- Получите стартовую руку из 4 карт

### 2. Ваш ход
1. **Получите ману**: +1 мана каждый ход (до 10)
2. **Возьмите карту**: автоматически в начале хода
3. **Играйте карты**: кликните на карту в руке
4. **Атакуйте**: кликните на своё существо, затем на цель
5. **Закончите ход**: нажмите кнопку "Закончить Ход"

### 3. Стратегия
- ⚖️ Балансируйте между атакой и защитой
- 💎 Эффективно используйте ману
- 🎯 Выбирайте правильные цели для атаки
- 🃏 Держите козыри для решающих моментов
- 📊 Следите за здоровьем и картами противника
